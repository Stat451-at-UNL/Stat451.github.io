Constructors

Good practice, but not required: constructor new_classname

new_simMatrix <- function(size = NULL) {
  if (is.null(size)) {
      size <- 0
  }
  dimnames= list(vector("character", size), vector("character", size))
  if (size > 0) dimnames <- list(as.character(1:size), as.character(1:size))
  structure(matrix(numeric(length= size*size), nrow=size, ncol=size,
                   dimnames = dimnames), 
            class = "simMatrix")
}

Validator

Validator: check that object is ‘right’

validate_simMatrix <- function(x) {
  # simMatrix is supposed to be a square matrix
  dims <- dim(x) 
  stopifnot(dims[1]==dims[2]) # matrix is supposed to be square
  values <- unclass(x)
  stopifnot(is.numeric(values)) 
  x
}

Helper for users

Focus here on the user, i.e. think about defaults and use cases

Constructor of the form class() to create a new object of class class

Providing support for generics, such as print

Constructor

Idea: create a new simMatrix and validate it

simMatrix <- function(size = NULL) {
  x <- new_simMatrix(size)
  validate_simMatrix(x)  
}

new_simMatrix only constructs one object at a time - can’t use that for casting a vector

Vectorized Constructor

simMatrix_one <- function(size = NULL) { # rename previous constructor
  x <- new_simMatrix(size)
  validate_simMatrix(x)  
}

simMatrix <- function(x) { # x can now be a vector of objects 
 lapply(x, FUN = simMatrix_one)
}

Inheritance

in 90% of situations classes aren’t started from scratch but use inheritances:

x <- new_simMatrix(1)
class(x) <- c("simMatrix", "matrix") # order matters: more specific first

creates a new object of new class that inherits all of the properties from the parent class simMatrix

that’s how ggplot2 extensions work (new geom and stat)

sloop::s3_dispatch(print(x))
   print.simMatrix
   print.matrix
=> print.default

A different constructor

By default simMatrix is called with a size argument.

What, if the input has the form of a data.frame with columns for row.names, column.names and value?

dframe <- data.frame(expand.grid(rows=paste0("L",1:6), cols=paste0("L",1:6)), 
                     value = runif(36))

simMatrix(dframe)
Error in `vector()`:
! invalid 'length' argument

Writing methods

simMatrix <- function(x, ...) {
  UseMethod("simMatrix")
}
simMatrix.numeric <- function(x, ...) {
  # interpret integer as size object
  new_simMatrix(size = x)
}

simMatrix.data.frame <- function(x, formula = value ~ rows+cols, ...) {
  mat <- xtabs(formula, data = x)
  class(mat) <- "simMatrix"
  validate_simMatrix(mat)
}
