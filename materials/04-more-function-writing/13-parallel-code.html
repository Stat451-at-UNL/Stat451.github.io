RNG in Parallel

clusterSetRNGStream uses RNG “L’Ecuyer-CMRG” that produces streams of independent random numbers

cl <- makeCluster(4)

clusterSetRNGStream(cl, 123)

results <- parLapply(cl, 1:4, function(i) {
  data.frame(i, runif=runif(5))
}) |> data.frame()

clusterSetRNGStream(cl, 123)

results2 <- parLapply(cl, 1:4,  function(i) {
  data.frame(i, runif=runif(5))
}) |> data.frame()

identical(results, results2)
[1] TRUE
stopCluster(cl)

When NOT to Parallelize

  • Small tasks
  • Fast vectorized code
  • Memory limits
